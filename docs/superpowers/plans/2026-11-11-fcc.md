# fcc (Fiction Compiler Collection) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Her formattaki e-kitabı, seçilebilir geliştirici çıktısı kamuflajları (kod, log, diff, test, build) içinde gösteren, panik tuşlu bir Textual terminal uygulaması.

**Architecture:** Tek yönlü akış: `loaders` dosyayı `Book` modeline çevirir → `Session` (UI'dan bağımsız okuma motoru) aktif `Mask` ve `noise` ile paragrafları `Line` listesine çevirir → Textual `FccApp` bunları `Feed` widget'ında gösterir. Durum `state.py` ile JSON'da tutulur.

**Tech Stack:** Python ≥ 3.11, Textual, PyMuPDF, ebooklib, beautifulsoup4, python-docx, odfpy, striprtf, mobi, pytest, pytest-asyncio.

**Spec:** `docs/superpowers/specs/2026-11-10-fcc-design.md`

## Global Constraints

- Ekranda ve `--version`/`--help` çıktısında kitap adı, "reader", "book", "okuyucu" kelimeleri geçmez (kod içi isimler serbest).
- Gürültü seviyesi 0–5; paragraf başına gürültü satırı sayısı `rng.randint(0, 2 * level)`; seviye 0 ⇒ gürültü yok.
- Gürültü satırları `is_book=False`; okuma ilerlemesine ve otomatik hıza sayılmaz.
- Durum dizini: Windows'ta `%APPDATA%\fcc\`, diğerlerinde `~/.config/fcc/`. Dosyalar: `config.json`, `progress.json`. Otomatik kayıt 10 sn'de bir + çıkışta; atomik yazım (geçici dosya + `os.replace`).
- `Book.id` = dosya içeriği SHA-256'sının ilk 16 hex hanesi.
- Okuma konumu `(chapter_index, paragraph_index)`.
- Resimler `[asset: <dosya-adı>]` paragrafı olarak temsil edilir.
- Mask adları: `code`, `log`, `diff`, `test`, `build`. `code` dilleri: `python`, `typescript`, `go`, `rust`, `java`, `csharp`.
- Terminal genişliği < 40 sütunda yeniden sarma + tek satırlık uyarı.
- Kapsam dışı: OCR, DRM kırma, Claude Code eklentisi, resim gösterimi.
- Tüm testler `pytest` ile, TDD sırasıyla (önce kırmızı test).

## Review Focus

1. **Tek kelimesi satır genişliğinden uzun paragraf** (URL, uzun Almanca kelime) → kelime zorla bölünür, metin kaybolmaz, çökme yok. *(Task 2 testi)*
2. **Boş ya da yalnızca boşluk içeren kitap** (0 paragraf) → mask üslubunda "metin bulunamadı" hatası, çökme yok. *(Task 1 ve Task 5 testleri)*
3. **Türkçe karakterli/boşluklu dosya yolu** (`D:\Kitaplar\Suç ve Ceza.epub`) → açılır, durum kaydı doğru yola işaret eder. *(Task 4 testi)*
4. **Okuma sırasında terminal yeniden boyutlandırma** → aynı paragraftan, yeni genişlikte yeniden sarılmış görünüm. *(Task 5 testi)*
5. **Geri gidip ileri gelince gürültünün değişmesi** (kamuflaj tutarsızlığı göze batar) → aynı paragraf her seferinde aynı gürültüyle çizilir. *(Task 3 testi)*

### Task 1: Proje iskeleti, kitap modeli, metin normalizasyonu, TXT/MD loader

**Files:**
- Create: `pyproject.toml`, `src/fcc/__init__.py`, `src/fcc/book.py`, `src/fcc/errors.py`, `src/fcc/text.py`, `src/fcc/loaders/__init__.py`, `src/fcc/loaders/base.py`, `src/fcc/loaders/text.py`, `.gitignore`
- Test: `tests/test_book.py`, `tests/test_text.py`, `tests/loaders/test_text_loader.py`

**Interfaces:**
- Produces:
  - `Paragraph(text: str)`, `Chapter(title: str | None, paragraphs: tuple[Paragraph, ...])`, `Book(id: str, chapters: tuple[Chapter, ...])` — hepsi `@dataclass(frozen=True)`; `Book.paragraph_count() -> int`, `Book.paragraph(pos: tuple[int,int]) -> Paragraph`, `Book.next_pos(pos) -> tuple[int,int] | None`, `Book.prev_pos(pos) -> tuple[int,int] | None`, `Book.index_of(pos) -> int` (0 tabanlı genel sıra).
  - `book_id(data: bytes) -> str`
  - `errors.py`: `FccError(Exception)`; alt sınıflar `UnsupportedFormat`, `DrmProtected`, `NoTextLayer`, `EmptyBook`. Her biri `title: str` (mask'te başlık olarak kullanılır) ve `str(e)` = açıklama.
  - `normalize_paragraphs(raw: list[str]) -> list[str]`: satır sonu tireli bölünmeleri birleştirir (`"kelime-\ndevam"` → `"kelimedevam"`), paragraf içi tek `\n`'leri boşluğa çevirir, boşlukları sadeleştirir, boşları atar.
  - `wrap(text: str, width: int) -> list[str]`: kelime sınırından böler; `width`'ten uzun kelimeyi zorla böler.
  - `Loader` Protocol: `name: str`, `extensions: tuple[str, ...]`, `can_load(path: Path, head: bytes) -> bool`, `load(path: Path) -> Book`.
  - `loaders.load_book(path: Path) -> Book`: `LOADERS` sırasıyla `can_load` olanları dener; `DrmProtected` ve `NoTextLayer` hemen yükseltilir; diğer hatalarda sıradakine geçer; hiçbiri başaramazsa `UnsupportedFormat`. Sonuçta 0 paragraf varsa `EmptyBook`.
